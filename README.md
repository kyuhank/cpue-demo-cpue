# CPUE analysis and reporting

Compare two CPUE analyses, then bring their results together in one report.

- **Inputs:** Extracted catch and effort records.
- **Outputs:** CPUE indices, comparison plots and tables, and a CPUE report.

Part of the [CPUE workflow demo](https://github.com/kyuhank/cpue-actions-demo), using synthetic data and toy models. Each run records the exact code commit and input/output hashes.

[Run the demo](https://kyuhank.github.io/cpue-actions-demo/) · [View job outputs](https://kyuhank.github.io/cpue-demo-cpue/)
